# studentMarksAnalyser

A modular, console-based JavaScript project designed to manage student data, compute academic metrics, and generate clean, formatted performance reports.

## Features
- **Input Validation:** Ensures marks are valid numbers between 0 and 100.
- **Statistical Calculations:** Instantly computes total marks, class average, highest, and lowest scores.
- **Automated Grading:** Assigns letter grades (`A`, `B`, `C`, `F`) based on performance thresholds.
- **Student Search:** Case-insensitive search feature to quickly look up individual student results.
- **Sorted Leaderboard:** Ranks students from highest to lowest marks automatically.
- **Error Handling:** Gracefully handles empty datasets, mismatched lengths, and invalid inputs (strings, negative numbers).

## Tech Stack
- **JavaScript (ES6+)**
- Node.js (Console Environment)
